[translit](https://kuzz0k.github.io/translit)

****

Переводит русский язык в транслит

введите ваше сообщение - BBeguTe Bawe coo6w,eHue

### Вкладки

**транслит**
- перевод прямо во время набора текста
- кнопка «Копировать» или Enter — копирует чистый текст, без шрифтов и цветов
- 🎲 — случайная фраза

**ник** — транслит, который можно использовать как никнейм: только латиница, цифры и `_`
(Жёлтый ёж → `XeJlTblu_eX`). Настройки:
- **слитно** — без `_` между словами
- **skill** — `xX_XeJlTblu_eX_Xx`
- **power** — тег в начале или в конце: `PRO_XeJlTblu_eX` / `XeJlTblu_eX_PRO`, можно выбрать готовый или написать свой

Есть счётчик длины и 🎲 — случайный ник.

**тренажёр** — как monkeytype, только транслитом: наберите пословицу
(Работа не волк → `pa6oTa He BoJlk`). Скорость, точность и рекорд.
`Tab` — новый текст, `Esc` — заново.

Можно установить как приложение на телефон или компьютер, работает без интернета.

### Разработка

Сделано на React + TypeScript + Vite.

```bash
npm install
npm run dev
```

`npm run typecheck` — проверка типов, `npm run build` — проверка типов и сборка в папку `dist`.

### Деплой

При каждом пуше в `main` GitHub Actions собирает сайт и публикует на GitHub Pages
(`.github/workflows/deploy.yml`). Один раз нужно включить в настройках репозитория:
**Settings → Pages → Source: GitHub Actions**.
